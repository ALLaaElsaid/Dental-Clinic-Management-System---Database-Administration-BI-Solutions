# Dental Clinic Management System - Database Administration & BI Solutions

A comprehensive **Database Management System (DBMS)** and **Business Intelligence (BI)** solution tailored for a dental clinic. This project focuses on architecting a highly efficient, normalized data structure and implementing analytical reporting layers to support informed, data-driven decision-making.

---

## Project Overview
This system streamlines clinical operations by bridging the gap between raw data and strategic insights. It covers the full data lifecycle, from conceptual modeling to advanced BI reporting.

## Key Highlights
*   **System Analysis:** Conducted comprehensive workflow analysis to define core operational requirements.
*   **Database Design:** Architected a scalable, normalized SQL Server schema ensuring data integrity and robust performance.
*   **Data Modeling:** Expertly crafted EERD models to manage appointments, patient records, and inventory.
*   **BI & Analytics:** Implemented analytical reports using **SSAS (SQL Server Analysis Services)** to track key performance metrics and trends.

## Technologies Used
*   **Database:** SQL Server (DBMS)
*   **Business Intelligence:** SSAS (SQL Server Analysis Services)
*   **Modeling:** Microsoft Visio (ERD & System Design)
